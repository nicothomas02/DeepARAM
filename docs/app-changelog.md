# DeepARAM app changelog

This file lists every change to the public desktop app (`apps/desktop`) and to the site code the app depends on. Newest is first.
Each change was merged as one squashed commit. To undo one, run `git revert <commit>` on `main` and open a pull request
with the result. You can also ask Claude in the project to revert it.
